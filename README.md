# ✨ Descubra seu Signo

Aplicação web desenvolvida para consultar signos zodiacais a partir da data de nascimento do usuário.

Projeto acadêmico desenvolvido durante o curso de **Análise e Desenvolvimento de Sistemas — UNOPAR**.

## 🚀 Tecnologias utilizadas

- **PHP:** processamento dos dados e identificação dos signos.
- **XML:** armazenamento dos 12 signos, períodos e descrições.
- **HTML5:** estrutura das páginas.
- **CSS3:** estilização e personalização da interface.
- **Bootstrap 5:** layout responsivo.

## 💻 Funcionalidades

- Consulta do signo pela data de nascimento.
- Identificação automática entre os 12 signos zodiacais.
- Exibição do nome e das características do signo.
- Validação da data informada.
- Tratamento de períodos que atravessam a virada do ano.
- Interface responsiva para computadores e dispositivos móveis.

## ⚙️ Como executar

1. Instale o XAMPP com suporte a Apache e PHP.
2. Baixe ou clone este repositório.
3. Coloque a pasta do projeto dentro de `C:\xampp\htdocs`.
4. Inicie o Apache pelo painel do XAMPP.
5. Acesse no navegador `http://localhost/consulta-signos-php/`.

**Observação:** o endereço deve corresponder ao nome da pasta utilizada dentro de `htdocs`.
